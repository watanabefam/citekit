# Hermes: project rules live in AGENTS.md

Before doing anything in this repository, read and follow **`AGENTS.md`** at the repo root. It is the
single source of truth for how to work here (commands, invariants, layout).

This file exists only because Hermes loads `.hermes.md` **in preference to** `AGENTS.md` ("first match
wins" — when both are present, only `.hermes.md` reaches the model), and because `.hermes.md` is
inherited from parents up to the git root while Hermes' `AGENTS.md` discovery is cwd-only. Every other
agent (OpenCode, Codex, Cursor, Windsurf, Cline, Copilot, Amp) reads `AGENTS.md` natively; Claude Code
reads `CLAUDE.md`, which imports it.

Do not duplicate the rules here — edit `AGENTS.md`.
